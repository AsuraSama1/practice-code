# Práctica Personal de Desarrollo de Código

Este repositorio es mi espacio personal de práctica y constante evolución en el desarrollo de software. Aquí documento y organizo los ejercicios, proyectos y retos de programación que realizo para fortalecer mis bases técnicas.

## 🛠️ Tecnologías y Herramientas
* **Lenguajes:** Java
* **Entorno de Desarrollo:** Visual Studio Code
* **Control de Versiones:** Git y GitHub

## 📂 Organización del Repositorio
El código está estructurado para separar los diferentes lenguajes y conceptos que voy practicando:
* **`/java`:** Programación Orientada a Objetos (clases, herencia, uso de `ArrayList`, manejo de entradas con `Scanner`, etc.).

## 🎯 Objetivo
Mantener el hábito diario de escritura de código limpio, aplicar buenas prácticas y demostrar constancia en mi aprendizaje dentro del desarrollo de software.
